# Migração do `salic_dbt` para `salic/` (ADRs 0010 e 0015) — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Levar os 599 modelos de `dbt/minc/models/salic_dbt/` para `dbt/minc/models/salic/`, com a camada no nome do arquivo e o schema igual ao nome da pasta, **sem mudar nenhum número**, e zerar as regras R1 e R7 do `verificar.py` para o SALIC.

**Architecture:** O SALIC é um banco dentro do Ministério. A ingestão v2 (Trino, ADR 0005) copia as tabelas dele, como texto, direto para o schema `salic_bronze`. Não existe raw: **`salic_bronze` já é a Bronze**, e as sources `bronze_sac`, `bronze_tabelas`, `bronze_agentes`, `bronze_controledeacesso` e `bronze_bdcorporativo` a declaram. Os 589 modelos gerados que tipam essas tabelas são **Silver** e passam a se chamar `silver_<origem>_<tabela>`, continuando a ler a source por `source()`. Os 10 modelos manuais (`core/`, `meta3/`, `meta4/`, `meta5/`) viram Silver ou Gold conforme o que fazem. Como a regra R3 hoje proíbe `source()` em silver, a decisão entra primeiro como ADR 0016 e ajuste do `verificar.py`, em PR separado, como exige o `docs/adr/GUIA.md`.

**Tech Stack:** dbt-core 1.10 (Postgres), macros `bronze_*` de `macros/bronze_salic/casts_bronze.sql`, `verificar.py` da skill `arquitetura-lakehouse-minc`, pytest, `make docs-collect`, `psql` pelo usuário (o agente não lê o `.env`).

```markdown
# ADR 0016 — Fonte sem raw: quando a ingestão já grava a cópia fiel, a source é a Bronze

- **Data:** 2026-10-27
- **Status:** proposto
- **Escopo:** regra R3 do ADR 0010 (o que a Silver pode ler) e a Bronze do SALIC
- **Substitui em parte:** ADR 0010, regra transversal "Silver lê a Bronze por `ref()`"; o resto continua valendo
- **Origem:** migração do `salic_dbt` (plano de 2026-10-27) e a pergunta aberta da R3 no Mapas

## Contexto

O ADR 0010 diz que a Silver lê a Bronze por `ref()` e nunca `source()`. Para
o SALIC ele mesmo previu a exceção ("a Bronze passa a ser `source` ou cópia
fiel"), mas o `verificar.py` só aceita `ref()`. Hoje 589 modelos do
`salic_dbt/bronze/` tipam tabelas do schema `salic_bronze` lendo-as por
`source()`, e 59 silvers do Mapas leem `source()` de tabelas `bronze_*` que
a DAG grava. Nos dois casos não há modelo Bronze porque a ingestão já
grava a cópia fiel: o SALIC é um banco interno do Ministério, copiado pelo
Trino direto para `salic_bronze` (ADR 0005), sem passar por raw no MinIO.

Criar 589 modelos `bronze_*` teria dois custos. Como `table`, duplica 157 M
de linhas (52,7 GB) sem nenhum uso. Como `view`, prende as tabelas de
`salic_bronze`: a ingestão v2 recria cada tabela com `DROP TABLE` pelo
Trino, que não tem `CASCADE`, e o Postgres recusa o `DROP` enquanto houver
view dependente.

## Decisão

1. Fonte copiada pela ingestão direto para o Postgres, sem raw, tem a Bronze
   na própria tabela gravada. Não se escreve modelo `bronze_*` para ela.
2. Essa Bronze é declarada como `source` com nome `bronze_<fonte>` (no SALIC,
   `bronze_sac`, `bronze_tabelas`, `bronze_agentes`, `bronze_controledeacesso`,
   `bronze_bdcorporativo`). O prefixo no nome da source é o que diz ao
   verificador que a source é Bronze.
3. A Silver dessa fonte lê a Bronze por `source('bronze_<fonte>', '<tabela>')`.
   Continua valendo o resto da R3: nada de `ref()` a outra fonte, nada de
   `source()` cujo nome não comece com `bronze_`.
4. Fonte que tem raw (TransfereGov, BB Ágil, SIDRA, Bacen, Ancine) continua
   com modelo `bronze_*` e a Silver lê por `ref()`, como no ADR 0010.

## Por quê

A Bronze é definida pelo que ela é (cópia fiel, tudo texto, sem filtro), não
por ser modelo dbt. Quando a ingestão entrega exatamente isso, o modelo
`bronze_*` só acrescentaria custo e um ponto de quebra na carga.

## O que foi descartado

- 589 `bronze_*` como `table`: duplicação sem leitor.
- 589 `bronze_*` como `view`: quebra o `DROP` da ingestão.
- Exceção por lista de pastas no `verificar.py`: lista cresce e ninguém
  lembra de atualizar; o prefixo na source é declarativo e aparece no diff.

## Consequências

- `verificar.py`: a R3 aceita `source()` cujo nome comece com `bronze_`.
- O Mapas pode zerar a R3 renomeando a source `mapas` para `bronze_mapas` num
  PR de modelos; este ADR não faz isso.
- `salic/bronze_sac_projetos` e `salic/bronze_sac_captacao` ficam
  redundantes; sair delas é PR próprio, com contagem.
- R9 (Bronze guarda histórico) continua manual e continua não cumprida pela
  ingestão com `DROP`; este ADR não muda isso.
```

#!/usr/bin/env python3
"""Migra um lote gerado do salic_dbt/bronze/<origem>/ para models/salic/.

Mecânico, e só o que a migração permite (ADR 0010, plano de 2026-10-27):
  - git mv de cada <origem>__<tabela>.sql para salic/silver_<origem>_<tabela>.sql,
    trocando só a primeira linha de comentário; o corpo SQL fica igual;
  - git mv do schema.yml para salic/schema_<origem>.yml, renomeando os blocos
    `- name:` e a frase "Camada bronze tipada" da descrição;
  - git mv do sources_<origem>.yml para salic/;
  - reescreve ref('<origem>__x') -> ref('silver_<origem>_x') em models/, tests/
    e macros/ do projeto dbt;
  - apaga a subpasta vazia.

Imprime tudo que fez e tudo que NÃO conseguiu fazer sozinho (bloco de schema
sem a frase padrão, por exemplo), para a pessoa terminar à mão.

Uso: python3 scripts/migrar_lote_salic.py controledeacesso
"""

from __future__ import annotations

import re
import subprocess
import sys
from pathlib import Path

RAIZ = Path(__file__).resolve().parents[1]
PROJETO = RAIZ / "dbt" / "minc"
ORIGEM_DIR = PROJETO / "models" / "salic_dbt" / "bronze"
DESTINO = PROJETO / "models" / "salic"
ORIGENS = ("controledeacesso", "bdcorporativo", "agentes", "tabelas", "sac")

RE_HEADER = re.compile(r"^-- Bronze SALIC — (?P<tabela>\S+?)(?P<view> \(VIEW na origem\))?\.$", re.M)
RE_DESC = re.compile(r"Camada bronze tipada a partir de\s+salic_bronze\.")


def git_mv(de: Path, para: Path) -> None:
    subprocess.run(["git", "mv", str(de), str(para)], check=True, cwd=RAIZ)


def novo_nome(stem: str, origem: str) -> str:
    assert stem.startswith(f"{origem}__"), stem
    return f"silver_{origem}_{stem[len(origem) + 2:]}"


def migrar_sql(origem: str) -> dict[str, str]:
    renomes: dict[str, str] = {}
    for sql in sorted((ORIGEM_DIR / origem).glob("*.sql")):
        novo = novo_nome(sql.stem, origem)
        renomes[sql.stem] = novo
        destino = DESTINO / f"{novo}.sql"
        assert not destino.exists(), f"já existe {destino}"
        git_mv(sql, destino)
        texto = destino.read_text(encoding="utf-8")
        texto, n = RE_HEADER.subn(
            lambda m: f"-- Silver SALIC — {novo} (ex-{m.group('tabela')}"
            f"{m.group('view') or ''}). Lê salic_bronze, a Bronze do SALIC (ADR 0016).",
            texto,
            count=1,
        )
        if n != 1:
            print(f"  ATENÇÃO cabeçalho fora do padrão, revisar à mão: {destino.name}")
        destino.write_text(texto, encoding="utf-8")
    print(f"{len(renomes)} .sql movidos")
    return renomes


def migrar_schema(origem: str, renomes: dict[str, str]) -> None:
    de = ORIGEM_DIR / origem / "schema.yml"
    para = DESTINO / f"schema_{origem}.yml"
    git_mv(de, para)
    texto = para.read_text(encoding="utf-8")
    faltam = []
    for velho, novo in renomes.items():
        texto, n = re.subn(rf"^(  - name: ){re.escape(velho)}$", rf"\g<1>{novo}", texto, flags=re.M)
        if n != 1:
            faltam.append(velho)
    texto, n_desc = RE_DESC.subn("Camada Silver tipada (ADR 0016: a Bronze é a source) a partir de salic_bronze.", texto)
    para.write_text(texto, encoding="utf-8")
    print(f"schema: {len(renomes) - len(faltam)} blocos renomeados, {n_desc} descrições ajustadas")
    if faltam:
        print(f"  ATENÇÃO blocos não encontrados no schema.yml: {faltam}")
    if n_desc != len(renomes):
        print(f"  ATENÇÃO {len(renomes) - n_desc} descrição(ões) sem a frase padrão; revisar à mão")


def migrar_sources(origem: str) -> None:
    de = ORIGEM_DIR / f"sources_{origem}.yml"
    if de.exists():
        git_mv(de, DESTINO / de.name)
        print(f"sources_{origem}.yml movido")


def reescrever_refs(renomes: dict[str, str]) -> None:
    alvos = list((PROJETO / "models").rglob("*.sql")) + list((PROJETO / "tests").glob("*.sql")) + list((PROJETO / "macros").rglob("*.sql"))
    padrao = re.compile(r"""ref\(\s*(['"])(""" + "|".join(map(re.escape, renomes)) + r""")\1\s*\)""")
    for arq in alvos:
        texto = arq.read_text(encoding="utf-8")
        novo, n = padrao.subn(lambda m: f"ref({m.group(1)}{renomes[m.group(2)]}{m.group(1)})", texto)
        if n:
            arq.write_text(novo, encoding="utf-8")
            print(f"  {n} ref() reescrito(s) em {arq.relative_to(RAIZ)}")


def main(argv: list[str]) -> int:
    origem = argv[1] if len(argv) > 1 else ""
    if origem not in ORIGENS:
        print(f"uso: {argv[0]} <{'|'.join(ORIGENS)}>")
        return 2
    renomes = migrar_sql(origem)
    migrar_schema(origem, renomes)
    migrar_sources(origem)
    reescrever_refs(renomes)
    pasta = ORIGEM_DIR / origem
    sobras = [p.name for p in pasta.iterdir()] if pasta.exists() else []
    if sobras:
        print(f"  ATENÇÃO sobrou em {pasta}: {sobras}")
    else:
        pasta.rmdir()
        print(f"{pasta.relative_to(RAIZ)} apagada")
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
